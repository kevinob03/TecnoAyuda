## Evidencias adicionales que solicita el ejercicio

El enunciado requiere capturas de la ejecución del script y de los resultados de las consultas. Para demostrar por separado todas las métricas, conviene guardar resultados reales de:

- CPC y CTR
- CAC y ROAS
- Conversiones entre las etapas del embudo
- Ciclo de venta y ticket promedio
- Comparación de métricas de vanidad y de negocio

**Cómo obtenerlas:** abrir [`../sql/TecnoAyuda_Completo.sql`](../sql/TecnoAyuda_Completo.sql) en MySQL Workbench, ejecutar cada consulta de métricas y tomar capturas mostrando tanto el SQL como su tabla de resultados. También revisar *Action Output* para identificar posibles errores. Subir las capturas PNG a esta carpeta.

Las pruebas de compatibilidad local en `verificacion/` no deben presentarse como capturas de un servidor MySQL. **No se han inventado resultados ni evidencias.**
